# SchoolPulse Presentation Deck

This directory contains the public-facing "Product Showcase" page for SchoolPulse.

## How to View
1.  **Online:** If GitHub Pages is enabled for this repository (Source: `/docs`), visit your GitHub Pages URL (e.g., `https://username.github.io/schoolpulse/`).
2.  **Locally:** Improved presentation can be seen by simply forcing `docs/index.html` to open in your browser.

## Tech Stack
-   **HTML5**
-   **Tailwind CSS (CDN)**: No build step required for this page.
-   **FontAwesome**: For icons.
-   **Google Fonts**: "Outfit" typeface.

## Purpose
Use this page when presenting the application to school administrators or parents to highight the "AI Advantage" and ease of use without needing to demo the live logged-in app immediately.
